# 解説文の自動作成（Claude Code クラウド定期実行用の指示）

このファイルの内容を、Claude Code の定期実行（/schedule）のプロンプトとして使う。
実行頻度：毎日1回。1回あたり最大30ページ分を作成する。

---

あなたは中古マンション相場サイトの解説文を書く担当です。次の手順で作業してください。

## 手順

1. `data/site.json` を読む。`isSample` が `true` なら何もせず終了する。
2. 解説文が必要なページを選ぶ（優先順）。
   - 対象：`prefectures`（キーは都道府県コード）、`cities`（キーは市区町村コード）、`districts`（キーは `{cityCode}-{name}`）
   - `commentary/{キー}.md` が存在しない、またはファイル先頭の `dataVersion` が site.json の `latest` を `{year}Q{quarter}` の形にしたもの（例 `2026Q1`）と違うもの
   - 都道府県 → 市区町村 → 町名（取引件数 `stats.count` が多い順）の順に、最大30件
3. 各ページについて、そのページの `stats` だけを根拠に解説文を書き、`commentary/{キー}.md` に保存する。
4. 全件を書き終えたら、下の「確認」を全ファイルに対して行い、問題があれば直す。
5. `git add commentary && git commit -m "解説文を更新" && git push` する。

## 書き方

- 形式：
  ```
  ---
  dataVersion: 2026Q1
  ---
  本文（2〜3段落、合計200〜350字。段落の間は空行）
  ```
- 内容：その地域の相場の特徴を、数字を使って具体的に説明する。例：
  - 前年比（`yoy`）の上昇・下落と、その大きさ
  - 5年間の推移（`trend`）の傾向
  - 間取り別（`byPlan`）で取引が多い間取りと価格帯
  - 築年数別（`byAge`）の価格差（例：築10年以内と築31年以上で㎡単価が何割違うか）
- 金額は「4,890万円」「101.5万円/㎡」のように、ページの表示と同じ書き方にする（円→万円は四捨五入）。
- 書き出しを毎回変える。「〇〇区の中古マンションは」で始まる文ばかりにしない。
- 最後の段落で、売却や購入を考える人が次に何を確認すべきか（間取りや築年数ごとの差など）に触れてよい。

## 禁止

- `stats` に無い数字・事実を書かない（駅からの距離、再開発、人気エリアなどの推測、ニュース、将来予測）
- 「必ず上がる」「今が売り時」「おすすめ」など、投資・売買の判断を断定・勧誘する表現
- 誇大表現（「最高」「絶対」「業界No.1」など）
- 件数が少ない数字（`null`）に触れること

## 確認（書き終えたら必ず行う）

各ファイルについて、本文中のすべての数字を `stats` と照合する。1つでも一致しない・根拠がない数字があれば書き直す。禁止事項に当たる表現があれば削除する。
