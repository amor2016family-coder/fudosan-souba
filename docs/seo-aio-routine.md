# SEO・AIOの定期点検（Claude Code クラウド定期実行用の指示）

毎月1回実行する。**サイトに直接反映してはいけない。** 必ずプルリクエスト（変更の提案）として出し、人の承認を待つ。
レイアウトの点検（`docs/layout-review-routine.md`）とは別で、こちらは**検索エンジンとAIからの集客**を担当する。

---

あなたはこのサイト（住まい相場 / https://sumaisouba.com ）の、検索エンジン対策（SEO）とAI検索対策（AIO）の担当です。

## 前提

- 静的サイト（Astro）。ページは `data/site.json` から自動生成される。
- 読者は「自宅がいくらで売れるか知りたい人」「購入前に相場を知りたい人」。
- 収益は売却査定サービスの紹介（アフィリエイト）。検索から来た人が相場を見て、査定に進む流れ。
- MEO（Googleマップ対策）は実店舗がないため対象外。

## 手順

1. `npm ci` のあと `npm run build` を実行し、`dist/` の出力を実際に読んで点検する。
2. 次の観点で確認し、**問題のある箇所を最大3件**まで直す。

### SEO（検索エンジン対策）
- `<title>` が各ページで重複していないか。地域名・年・内容が入っているか。32文字前後に収まっているか
- `description` が各ページ固有で、数字（価格や件数）を含んでいるか。120文字前後か
- 見出し（h1→h2→h3）の順序が崩れていないか。h1は1ページ1つか
- 内部リンク：どのページからも3クリック以内で到達できるか。関連ページ（近隣エリア、同じ市区町村の町名）へのリンクがあるか
- `sitemap.xml` と `robots.txt` が正しく出力されているか
- 構造化データ（JSON-LD）が壊れていないか：WebSite / BreadcrumbList / FAQPage / Dataset
- 画像や外部読み込みを増やして表示が遅くなっていないか

### AIO（AI検索・AI回答への対策）
- `llms.txt` の内容が最新か（掲載件数、最新データの時期、更新日）
- 各ページの冒頭に「このページの要点」があり、**そのページだけ読めば答えが分かる**書き方になっているか
- 数値には必ず「いつの」「何件を集計した」「中央値である」という条件が添えられているか
- 出典（国土交通省 不動産情報ライブラリ）が本文中に明記されているか
- よくある質問が、人が実際に検索する言い回しになっているか
- `robots.txt` で主要なAIクローラー（GPTBot、ClaudeBot、PerplexityBot など）が許可されているか

## 禁止

- `main` への直接コミット、履歴の書き換え（force push）
- `data/`、`commentary/`、`scripts/`、`.github/` の変更
- 新しいライブラリの追加、JavaScriptに依存する表示
- 表示している数字の意味や計算方法の変更
- キーワードの詰め込み、隠しテキスト、相互リンクの購入など、検索エンジンの規約に反する手法
- 事実でない記述（将来予測、「必ず高く売れる」などの訴求）

## 提出

新しいブランチ（例 `seo/2026-11`）を作り、`npm run build` が通ることを確認してから `gh pr create` でプルリクエストを作る。本文には日本語で次を書く。

- 直した点（箇条書き3つまで）と、その理由
- 点検したが問題がなかった項目（一覧で簡潔に）
- 次回以降に回したこと

**マージはしない。** 承認は人が行う。
